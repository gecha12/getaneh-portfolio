# 02 — Technology Stack

## 1. Frontend Technologies
- **React (`18.3.1`)**: Component-based reactive UI library supporting concurrent rendering, modular state, and synthetic event handling.
- **TypeScript (`5.6.3`)**: Strict static type checking ensuring contract fidelity across project models, security labs, and interactive modals.
- **Vite (`5.4.10`)**: ESM-based build toolchain and development server providing lightning-fast HMR and optimized Rollup production tree-shaking.
- **Lucide React (`0.460.0`)**: Tree-shakeable SVG icon set maintaining crisp visual fidelity with zero bundle bloat.
- **Custom CSS3 & CSS Variables**: Centralized design system tokens for color, typography, elevation, and transitions without runtime CSS-in-JS overhead.

---

## 2. Target Full-Stack & Backend Systems (Showcased Projects)
- **Python (FastAPI & Django)**:
  - Asynchronous endpoint routing with `asyncio`.
  - Pydantic models for request serialization and payload validation.
  - Joblib serialization for serving trained ML inference artifacts.
- **Java (Spring Boot)**:
  - Microservices architecture and enterprise persistence patterns.
  - Spring Security integration and Role-Based Access Control (RBAC).
- **PostgreSQL & Relational Databases**:
  - ACID compliant database architecture.
  - Schema normalization, indexing, and foreign key constraint enforcement.
- **Docker & Containerization**:
  - Multi-stage Dockerfiles for minimal production images and consistent runtime environments.

---

## 3. Machine Learning & Data Science Tooling
- **Scikit-Learn**: Supervised learning models (Random Forests, Logistic Regression, Decision Trees).
- **Pandas & NumPy**: Exploratory Data Analysis (EDA), missing value handling, numerical scaling (StandardScaler/MinMax), and feature encoding.
- **Validation Frameworks**: Stratified K-Fold cross-validation, confusion matrices, precision/recall, and ROC-AUC curves.

---

## 4. Cybersecurity & DevSecOps Tools
- **OWASP Top 10**: Vulnerability discovery and remediation (SQL Injection, XSS, CSRF, BOLA).
- **Wireshark**: Deep packet inspection, TCP stream reconstruction, and anomalous DNS traffic detection.
- **Nmap**: Network reconnaissance, service banner grabbing, and port state analysis.
- **Burp Suite**: HTTP/HTTPS proxy inspection, payload tampering, and header analysis.
- **Wazuh HIDS**: Open-source host intrusion detection, file integrity monitoring (FIM), and security event log triage.
