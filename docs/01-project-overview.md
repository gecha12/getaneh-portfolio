## 3. Core Problem & Solution

### The Problem
Most entry-level developer portfolios suffer from:
- Generic, repetitive dark templates with poor visual contrast.
- Superficial skill listings without concrete verification or case studies.
- Lack of security considerations (e.g. vulnerable forms, exposed API keys, spam vulnerabilities).
- Ineffective resume delivery (flat screenshots or broken formatting).

### The Engineering Solution
- **Visual Identity**: "Emerald Forest + Neon Lime + Charcoal" delivering high-contrast, WCAG AA compliant visual hierarchy with custom SVG dual-concentric orbital animations.
- **Deep Technical Case Studies**: Integrated modals showcasing System Architecture, Problem Statements, Concrete Solutions, and distinction between Verified Features and Future Roadmaps.
- **Dual-Mode Professional CV**: Integrated interactive preview modal and an ATS-friendly, print-ready standalone A4 document (`/cv.html`).
- **Security-First Architecture**: Built-in honeypot bot trap, submission cooldown gates, and sanitized transmission feedback.
